⚠ 這一頁不能直接點檔案打開

你是從資料夾裡雙擊 app.html 打開的，瀏覽器會擋住程式，按鈕都不會動。請從 Chrome 工具列的「物件上架助手」圖示打開（沒裝的話先照 README 裝）。

物件上架助手

貼上愛屋型錄（或自己打的物件文字）→ 解析 → 補紅底 → 按「上架到 591」，外掛把刊登表單填好。「保存資料」與「立即支付」永遠由你自己按。

⚙ 我的資料（只存在你自己的 Chrome，填一次就好）

物件名稱開頭：每一戶標題（④ 的廣告標題、樂屋的物件名稱）最前面固定加的字，留空就不加。 開頭佔掉的字也算進標題字數：591 上限 30 字，樂屋上限 25 字（超過的會被截掉，④ 會提醒）。

固定尾段的樣式（選填）：字級、粗體、底線整段共用；文字顏色和底色一行一行各自選。 只套在固定尾段，抬頭與 ✨ 特色行固定套粗體18px（不能自訂、沒有開關，見④）。591 不支援底線（貼上去會被拿掉，樂屋看得到）；沒設任何樣式就跟以前一樣貼純文字。

固定尾段填了字才能一行一行選顏色。

預覽

封面貼圖（選填，2026-09-24 新增）：存一張圖（建議去背人像＋落款帶，先用「批次貼圖」工具的「封面貼圖」功能抓位置感覺）。 解析型錄後，會自動把這張圖合成到抓回來的第一張照片（591 封面）上——滿版寬、貼齊底部，不用再另外開網頁手動貼。只存一張，換人就重新上傳蓋掉。

① 貼上資料

直接貼型錄頁的網址（一行就好）：外掛會自動抓回來解析、照片也自動帶，不用按「顯示」也不用自己複製。 門牌沒帶到的話（型錄本來就沒填，或這戶沒開放看門牌），③ 自己補一下就好。 也可以照舊：打開型錄頁，先把地址旁的「顯示」點開 → Ctrl+A → Ctrl+C → 貼在這裡； 或貼自己打的物件文字（第一行標題／地址：／售價：或租金：／格局：／坪數：／樓層：／✨ 特色行）。

    ⑥ 上架到 591／樂屋

    紅底補完再按哪個平台。會開一個刊登分頁自動填，右下角面板會一行一行報進度、最後列出還缺什麼。填的時候不要切到別的分頁；看到「✅ 填完」後從上往下核對，最後自己按 591 的「保存資料，下一步」、或樂屋的「庫存」／「上架」——兩個平台分開按，要哪個平台就按哪顆。分開按、或按「一起上架」都可以：一起上架會先填 591，591 填完自動開樂屋分頁接著填，兩邊各自核對、各自按保存／上架。要先在 Chrome 登入該平台。
