# 591 自動填表

把物件資料庫的一筆物件，用 Playwright 填進 591 的刊登表單。

**只填，不送出。** 送出那一下永遠是你自己按。

---

## 為什麼是這個做法

591 沒有給個人房仲的官方刊登 API（只有品牌總部級的 B2B 合約）。要自動化就只剩
「模擬人操作瀏覽器」這條路。這條路做得到，但有兩個真實成本：

1. **591 服務條款禁止程式操作。** 用自己的帳號、正常速度、只上架自己有委託的案件，
   實務上不太會出事；**批次連發、半夜跑一百筆，很容易被判定異常鎖帳號。**
2. **591 一改版就會壞。** 這是所有瀏覽器自動化的通病，躲不掉。

所以這個工具的設計不是「越自動越好」，而是「壞掉的時候要好修、出事的機率要壓到最低」：

- 欄位對映全部外部化到 `config/selectors.json` —— 591 改版只改這個檔，程式碼不動
- 一次一筆，沒有批次迴圈
- 每格之間停 0.2～0.6 秒（也是為了等 591 的連動欄位生出來）
- 填完停住，等你檢查
- 照片不自動傳（591 是上傳檔案，程式手上只有網址），但會印出正確順序

---

## 最簡單的用法：點桌面的三個 .bat

| 點這個 | 什麼時候點 |
|---|---|
| `591登入.bat` | 第一次，以及登入過期時 |
| `591抄欄位.bat` | 第一次，以及 591 改版壞掉時 |
| `591填表.bat` | **每次要上架物件** |

不用開終端機、不用打指令、不用記物件 id（填表那支會列清單讓你選編號）。
下面是同樣三件事的指令版，給需要時參考。

---

## 指令版：三步

### 第 0 步　安裝（只做一次，**已經幫你裝好了**）

```bash
cd C:\Users\ming\Desktop\Agent-OS\card-booking\tools\591-autofill; npm install
```

用的是你電腦上已經裝好的 Chrome，不會另外下載 150MB 的瀏覽器。

### 第 1 步　存登入狀態

```bash
cd C:\Users\ming\Desktop\Agent-OS\card-booking\tools\591-autofill; npm run login
```

會開一個瀏覽器視窗。**你自己登入 591**（含簡訊驗證），登入完回終端機按 Enter。

- 這支腳本**不會**幫你打帳密，也看不到你的帳密。它只在你按 Enter 之後把 cookie 存起來。
- 存出來的 `auth/591-state.json` **等同你的帳號鑰匙**。已經進 `.gitignore`，
  不要 commit、不要貼給別人、不要放雲端硬碟。
- 591 的登入會過期，過期就再跑一次這支。

### 第 2 步　抄下 591 表單的欄位

```bash
cd C:\Users\ming\Desktop\Agent-OS\card-booking\tools\591-autofill; npm run inspect
```

會開瀏覽器。**你自己導航到「刊登物件」那一頁**，開到平常填的表單畫面，回來按 Enter。

程式會把那一頁每個輸入框的 id／name／旁邊的標籤全部抄下來，存成
`config/form-dump.json`，並拍一張整頁截圖。

**把 `config/form-dump.json` 貼回對話裡給我**，我照它填好 `config/selectors.json`。

> 這一步不能省。我沒有 591 帳號、看不到那個表單，硬猜選擇器的結果是填錯格子、
> 上架錯資料 —— 這個專案的規矩是「不知道就不要猜」。

### 第 3 步　填

```bash
cd C:\Users\ming\Desktop\Agent-OS\card-booking\tools\591-autofill; node fill.mjs 物件id
```

物件 id 在後台網址列裡：`/admin/properties/`**`這一段`**

程式會逐格填、每格印出填了什麼，最後停住。然後換你：

1. 從頭看一遍每格對不對
2. 照終端機印出的順序把照片拖進去
3. 自己按送出

---

## 之後每次上架

只有第 3 步。第 1 步只在登入過期時重跑，第 2 步只在 591 改版時重跑。

---

## 591 改版壞掉了怎麼辦

症狀：某幾格印出 `✗ 失敗`。

修法：重跑 `npm run inspect`，把新的 `config/form-dump.json` 貼給我換掉 selector。
**程式碼不用動**，這就是把對映外部化的用意。

## 檔案

| 檔案 | 做什麼 |
|---|---|
| `save-login.mjs` | 開瀏覽器讓你自己登入，存 cookie |
| `inspect-form.mjs` | 抄下 591 表單的欄位結構 |
| `fill.mjs` | 主程式：讀物件 → 填表 → 停住 |
| `_shared.mjs` | 三支共用（讀 env、`@/` 別名、取上架包、人工節奏） |
| `config/selectors.json` | **唯一要維護的檔** —— 591 欄位對映 |
| `config/form-dump.json` | inspect 的產出（不進版控） |
| `auth/591-state.json` | 🔴 登入 cookie（不進版控） |
| `shots/` | 每次跑的截圖（不進版控） |

填進去的內容跟後台那頁「產生 591 上架包」是**同一個函式**（`src/lib/export-591.ts`）
產生的，不會出現「後台顯示 A、自動填表填 B」。
